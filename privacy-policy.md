# Privacy Policy
**Last Updated:** 2026-02-19

This application operates an Instagram Business account that automatically posts content and responds to messages and comments using AI-based processing.

---

## 1. Information We Collect

When users interact with the Instagram account, the application may collect:

- Instagram username
- Instagram user ID
- Message content
- Comment content
- Media metadata (where applicable)
- Interaction timestamps

This information is collected only when users voluntarily interact with the account via direct message or public comment.

---

## 2. How Information Is Used

Collected data is used to:

- Generate automated AI responses
- Maintain conversational continuity
- Provide context-aware replies
- Operate and improve the account's automated functionality

Responses are generated by automated AI systems.

---

## 3. Data Storage and Retention

Conversation data is stored on a self-hosted server for continuity purposes. Data is retained for a maximum of **30 days**, after which it is automatically deleted unless removed earlier upon request.

---

## 4. Third-Party Processing

AI responses are primarily generated using a self-hosted language model. In certain cases, message content may be processed by a third-party cloud AI provider to generate a response. This processing is limited to the content necessary to generate that response. No user data is sold or used for advertising purposes.

---

## 5. Data Deletion Instructions

Users may request deletion of their stored data at any time by:

- Sending a direct message containing the word: **DELETE**

Upon receiving a valid deletion request, all stored data associated with that user will be removed.

Users may also contact us at: **Email:** miso@jory.dev
